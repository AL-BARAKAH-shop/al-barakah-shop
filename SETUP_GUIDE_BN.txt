GOOGLE APPS SCRIPT
------------------
আপনার /exec URL script.js-এ already configured। Code.gs-এর deployment URL পরিবর্তন করলে script.js-এর APPS_SCRIPT_URL-ও পরিবর্তন করতে হবে।

GITHUB PAGES
------------
1. GitHub-এ নতুন repository তৈরি করুন।
2. এই ZIP-এর সব file repository-এর root-এ upload করুন।
3. Settings > Pages > Build and deployment > Source: Deploy from a branch
4. Branch: main
5. Folder: /(root)
6. Save
7. কয়েক মিনিট পরে Visit site থেকে website খুলুন।
